# DNA Connector release notes

## What is it?

This page documents version history for the Fiserv DNA Connector, including new features, improvements, and bug fixes by release.

## 26

### 26.0.0

2026 March

#### What's new

:eight_spoked_asterisk: Added ACS integration support. SMARunDNAJob now submits job status requests through the file named by the `SMA_MSLSAM_ACS_STATUS_FILENAME` environment variable when that variable is present. The ACS environment sets it, so no configuration is required.

#### Why this matters

ACS integration support allows the DNA Connector to submit status requests through ACS, enabling environments where the connector communicates with ACS rather than directly with OpCon.

#### Bug fixes

:white_check_mark: Fixed response file name collision in concurrent DNA jobs where two jobs running simultaneously on different machines could generate identical temporary response file names when sharing the same OS process ID.

### 21.2.2

2022 June

#### What's new

:eight_spoked_asterisk: Added the `-CycleCodeNotRequired` argument to the command line generated by the Fiserv DNA job sub-type, allowing a job with cycle codes defined in the database to run without cycle codes specified on the command line. See [Command-line options](./reference/command-line.md).

### 21.2.0

2022 May

#### Bug fixes

:white_check_mark: Corrected an invalid argument in the Oracle connection string that could prevent SMARunDNAJob from connecting.

### 21.1.0.1

2021 February

#### What's new

:eight_spoked_asterisk: Added the Fiserv DNA sub-type to the DDI definitions, so schedules imported by the Convert DNA Template program carry the correct job sub-type.
